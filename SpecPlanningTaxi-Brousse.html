Vue d'ensemble

Le module gère l'ensemble du cycle de planification d'une coopérative de taxi-brousse : création de templates hebdomadaires → génération automatique des DepartureSlots pour un mois entier → affectation manuelle des véhicules à chaque départ → consultation de l'état du parking au jour le jour.

Le fichier est auto-suffisant : il ne dépend que de React (exposé globalement via CDN Babel standalone) et des constantes globales TYPE (typographies) et de la palette pal passée en prop.

Fonctions utilitaires

t2m(time)

Convertit "HH:MM" en minutes depuis minuit.
"06:30" → 390

m2t(minutes)

Minutes → "HH:MM". Gère le dépassement minuit via % 1440.
1500 → "01:00"

addMinP(time, min)

Ajoute des minutes à une heure string.
addMinP("22:00", 270) → "02:30"

slotsOverlap(dep1,arr1,dep2,arr2)

Détecte le chevauchement horaire entre deux créneaux. Si arrivée ≤ départ, ajoute 1440 (passage minuit). Retourne boolean.

isoFmtP(iso)

Formate une date ISO en français.
"2026-06-09" → "9 Jun 2026"

dowFrP(iso)

Jour de la semaine abrégé.
"2026-06-09" → "Mar"

isWeekendP(iso)

Retourne true si samedi (6) ou dimanche (0). Utilise T12:00:00 pour éviter les décalages UTC.

fmtDurP(min)

Durée lisible.
270 → "4h30" · 120 → "2h"

buildMonthGridP(year, month)

Retourne un tableau de 35 ou 42 cases (null pour le rembourrage), premier jour = Lundi. Ex : si le 1er est un Mercredi, les 2 premières cases sont null.

genSlotsFromTpl(tpl, year, month)

Génère tous les DepartureSlots d'un mois depuis un template. Distingue semaine / week-end pour le nombre de véhicules. Calcule arrivalTime automatiquement.

applyTpl(tpl)

// Génère le mois, remplace uniquement les slots existants avec même coopId + mois + templateId
const gen = genSlotsFromTpl(tpl, applyYear, applyMonth);
const pfx = `${applyYear}-${pad(applyMonth)}`;
setSlots(prev => [
  ...prev.filter(s => !(s.coopId === coopId && s.date.startsWith(pfx) && s.templateId === tpl.id)),
  ...gen
]);

Logique métier

Génération de slots depuis un template

  • 1
    Itérer tous les jours du mois (1 → last day)
  • 2
    Pour chaque jour, déterminer week-end via isWeekendP
  • 3
    Pour chaque route × créneau, choisir weekendCount ou weekdayCount
  • 4
    Si count = 0 → skip. Sinon créer 1 DepartureSlot avec N vehicleSlots placeholder
  • 5
    arrivalTime = addMinP(sc.time, route.durationMin)
  • 6
    IDs uniques via séquence monotone seq = Date.now() incrémentée

Détection de conflit véhicule

// Dans VehicleAssignModal.getConflict(vId)
const others = allSlots.filter(s =>
  s.coopId === ds.coopId &&   // même coop
  s.date === ds.date &&        // même jour
  s.id !== ds.id &&            // pas le slot courant
  s.vehicleSlots.some(vs => vs.vehicleId === vId)  // véhicule déjà assigné
);
for (const o of others) {
  if (slotsOverlap(ds.departureTime, ds.arrivalTime, o.departureTime, o.arrivalTime))
    return `${o.from.slice(0,3)}→${o.to} ${o.departureTime}`;
}

Calcul d'occupation

// Dans DayDetailView
const totalCap = ds.vehicleSlots.reduce((s, vs) => {
  const v = vehicles.find(x => x.id === vs.vehicleId);
  return s + (v ? v.seats : 0);
}, 0);
const sold = dayResas
  .filter(r => ds.vehicleSlots.some(vs => vs.vehicleId === r.vehicleId))
  .reduce((s, r) => s + (r.seats || 0), 0);
const occupancyPct = totalCap > 0 ? Math.round(sold / totalCap * 100) : 0;

Couleur de la barre : >85% → #EF4444, >60% → #F59E0B, sinon pal.primary.

Conversion date réservation

Les réservations ont le format "DD/MM/YYYY". Conversion :

const [d, m, y] = (r.date || '').split('/').map(Number);
const iso = `${y}-${String(m).padStart(2,'0')}-${String(d).padStart(2,'0')}`;

Mise à jour immutable des slots

// Assigner un véhicule
onUpdateSlots(prev => prev.map(ds => {
  if (ds.id !== dsId) return ds;
  const vSlots = ds.vehicleSlots.map((v, i) =>
    i === vsIndex
      ? { ...v, vehicleId, status: vehicleId ? 'planned' : 'placeholder' }
      : v
  );
  return { ...ds, vehicleSlots: vSlots };
}));
